免許更新の予約空きまとめ

公式の予約サイトで会場ごとに分かれている空き状況カレンダーを、1つの表にまとめて見るためのブックマークレットです。

← トップへ戻る
このツールについて

警視庁の運転免許手続予約サイトでは、空き状況カレンダーは会場を1つずつ選んで見る仕組みになっています。このツールは、ログイン済みの公式サイトのページでブックマークレットを実行すると、公式サイトがカレンダー表示に使っているデータ（カレンダーAPI）を読み取り、全17会場の当月・翌月分を1つの表にまとめて表示するツールです。データを読むだけで、予約を確定することはありません。

個人情報の扱い：予約用IDなどの情報は、お使いのブラウザの中だけで扱われます。このブックマークレットが通信するのは、公式サイトのカレンダーデータ（API）だけです。会場・月・講習区分の条件を送って空きデータを受け取る読み取り専用の通信で、予約用IDなどを外部のサーバーへ送信する処理は一切入っていません。ソースコードを下に全文公開していますので、実行前に中身を確認できます。

使い方（3ステップ）

1
公式予約サイトでログインし、カレンダーを1回表示する
警視庁運転免許手続予約サイトを開き、いつも通りご自身で手続を進めて、会場を選んで「進む」を押し、空き状況カレンダーを1回表示します。（このツールは、カレンダー表示のときに読み込まれるデータを使って集約するため、このひと手間が必要です）
2
用意したブックマークを実行する
このページのコードを登録したブックマークを、公式予約サイトの画面を開いた状態で実行します。ブックマークの登録は最初の1回だけです（登録方法は下の「ブックマークの登録方法」へ）。
3
会場ごとの空き一覧が表示される
全17会場の当月・翌月分を読み取り、ページの先頭にまとめた表が表示されます。数字はその日に空いている予約枠の合計、×は空きなしです。読み取れなかった会場・月には、理由もあわせて表示されます。

実行する画面について：カレンダーを1回表示した後であれば、公式予約サイトのどの画面で実行しても全会場分を集約します。カレンダーをまだ表示していない状態で実行した場合は、その旨の案内が表示されます。

ブックマークの登録方法

最初に1回だけ、このページのコードをブラウザのブックマークに登録します。スマートフォン向けの手順を先に載せています。

まず、コードをコピーしてください
下のボタンを押すと、ブックマークに登録するためのコード（ブックマークレット）がコピーされます。

コピーしました

ボタンでコピーできない場合は、上の欄の文字列を長押し（タップ）で全選択してコピーしてください。コードは「javascript:」で始まる長い文字列です。1文字も変えず、そのまま使います。

iPhone（Safari）の場合
  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Safariでこのページをブックマークに追加します。共有ボタン（四角から矢印が出たマーク）を押し、「ブックマークを追加」を選んで保存します。名前は「空きまとめ」など、短くて分かりやすいものにしておくと後の手順が楽です。
  3. Safariのブックマークを開き、「編集」を押して、今作ったブックマークを選びます。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインしてカレンダーを1回表示した後で、ブックマークを開いて「空きまとめ」をタップすると実行されます。
  6. もう一つの実行方法：公式サイトを開いた状態で、アドレスバーにブックマーク名（例：空きまとめ）と入力すると候補に表示されるので、それをタップしても実行できます。

iPhone（ショートカットアプリ）の場合 ― ブックマーク登録が面倒な方へ

iPhoneの「ショートカット」アプリを使う方法もあります。下のボタンからショートカットを追加しておくと、公式サイトの画面から共有シートを開いてタップするだけで実行できます。中身（集約の仕組み）はブックマークレットと同じで、実行する仕組みが違うだけです。追加は最初の1回だけです。

ショートカットを追加する（タップで追加）

追加できたら：公式予約サイトでログインしてカレンダーを1回表示した後、Safariの共有ボタンからこのショートカット（「空きまとめ」）を選ぶと実行され、空き一覧が表示されます。

リンクが開けない場合は、手作業でも作れます

まず、ショートカット用のコードをコピーしてください
下のボタンを押すと、ショートカットに貼るためのコードがコピーされます。ブックマークレット用とは別のコードなので、こちらを使ってください。

コピーしました

ボタンでコピーできない場合は、上の欄の文字列を長押し（タップ）で全選択してコピーしてください。コードは1文字も変えず、そのまま貼ります。

  1. 「ショートカット」アプリを開き、右上の「＋」をタップして新規作成します。名前は「空きまとめ」など、分かりやすいものにしておきます。
  2. 「アクションを追加」から「WebページでJavaScriptを実行」を検索して追加します。
  3. アクションの中のコード欄に、コピーしたコードを貼り付けます（最初から入っている例のコードは、全部消してから貼ってください）。
  4. ショートカットの詳細設定で、入力を「SafariのWebページ」に設定し、「共有シートに表示」をオンにします。
  5. 使い方：公式予約サイトでログインしてカレンダーを1回表示した後、Safariの共有ボタンからこのショートカットを選ぶと実行され、空き一覧が表示されます。
Android（Chrome）の場合
  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Chromeでこのページをブックマークします（アドレスバーの☆、またはメニューの「スター」）。
  3. メニューの「ブックマーク」から今のブックマークを開き、「編集」を押します。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインしてカレンダーを1回表示した後で、アドレスバーにブックマーク名を入力し、候補に出てきたものをタップすると実行されます（ブックマークの一覧からタップしただけでは実行されないことがあるため、この方法が確実です）。
パソコンの場合

下のボタンをブックマークバーへドラッグして登録します。登録後は、公式サイトでカレンダーを1回表示してから、そのブックマークをクリックすると実行されます。

(function () {

  /* 会場名と placecode（公式カレンダーAPIの会場コード） */
  var VENUES = [
    ["府中試験場", "270"], ["鮫洲試験場", "280"], ["江東試験場", "250"], ["神田センター", "281"], ["新宿センター", "271"],
    ["田園調布署", "201"], ["世田谷署", "259"], ["成城署", "283"], ["板橋署", "553"], ["石神井署", "588"],
    ["下谷署", "614"], ["竹の塚署", "703"], ["本所署", "734"], ["立川署", "871"], ["青梅署", "803"], ["高尾署", "773"], ["町田署", "846"]

  /* ---- 表示（公式サイトの CSP で弾かれないよう、style 属性を使わずプレゼンテーション属性だけで組む） ---- */
  function el(tag, text) {
    var e = document.createElement(tag);
    if (text != null) e.textContent = text;
    return e;
  }
  function redBold(text) {
    var f = el("font");
    f.setAttribute("color", "#b00020");
    f.appendChild(el("strong", text));
    return f;
  }
  function showOverlay(build) {
    var old = document.getElementById(ROOT_ID);
    if (old) old.remove();
    var root = el("div");
    root.id = ROOT_ID;
    var outer = el("table");
    outer.setAttribute("width", "100%");
    outer.setAttribute("border", "2");
    outer.setAttribute("cellspacing", "0");
    outer.setAttribute("cellpadding", "10");
    outer.setAttribute("bgcolor", "#ffffff");
    var ob = el("tbody");
    var otr = el("tr");
    var otd = el("td");
    var ht = el("table");

    ht.setAttribute("cellspacing", "0");
    ht.setAttribute("cellpadding", "6");
    var hb = el("tbody");
    var hr = el("tr");
    var htd1 = el("td");
    htd1.setAttribute("bgcolor", "#12283f");
    var fnt = el("font");
    fnt.setAttribute("color", "#ffffff");
    fnt.appendChild(el("strong", "免許更新 空き状況まとめ"));

    otd.appendChild(ht);
    build(otd);
    otr.appendChild(otd);
    ob.appendChild(otr);
    outer.appendChild(ob);
    root.appendChild(outer);
    if (document.body) {
      document.body.insertBefore(root, document.body.firstChild);
      try { window.scrollTo(0, 0); } catch (e) { /* スクロールできなくても表示はする */ }
    }
    return root;
  }
  function failMessage(root, extra) {
    var p1 = el("p");
    p1.appendChild(redBold("空き状況を読み取れませんでした。"));
    root.appendChild(p1);
    root.appendChild(el("p", "このツールは、実際の予約サイトの仕組みによっては動作しない場合があります。お手数ですが、空き状況は公式サイトの「空き状況カレンダー」で会場ごとにご確認ください。" + (extra || "")));
  }
  /* 公式サイト自身がカレンダー表示のときに呼んだ calgetres の URL をブラウザの記録から探し、
     通信先（API）と講習区分（coursecode）を再利用する。見つからなければ null */
  function findApiContext() {
    var entries = [];
    try { entries = performance.getEntriesByType("resource") || []; } catch (e) { return null; }
    for (var i = entries.length - 1; i >= 0; i--) {
      var name = entries[i].name || "";
      if (name.indexOf("calgetres") < 0) continue;
      try {
        var u = new URL(name);
        var cc = u.searchParams.get("coursecode");
        if (!cc) continue;
        return { base: u.origin + u.pathname, coursecode: cc };
      } catch (e) { /* 次の候補を見る */ }
    }
    return null;
  }
  function pad2(n) { return (n < 10 ? "0" : "") + n; }
  /* 実行した日のローカル日付。ymd は "YYYYMMDD" 形式で、API の日付文字列とそのまま大小比較できる */
  function todayInfo() {
    var n = new Date();
    return { ymd: String(n.getFullYear()) + pad2(n.getMonth() + 1) + pad2(n.getDate()), day: n.getDate() };
  }
  /* 対象は当月と翌月 */
  function monthKeys() {
    var now = new Date();
    var list = [];
    for (var i = 0; i < 2; i++) {
      var d = new Date(now.getFullYear(), now.getMonth() + i, 1);
      var y = d.getFullYear();
      var m = d.getMonth() + 1;
      var last = new Date(y, m, 0).getDate();
      list.push({ ym: String(y) + pad2(m), label: y + "年" + m + "月", y: y, m: m, lastDay: last });
    }
    return list;
  }
  /* 1会場・1月分を公式カレンダーAPIから読む。
     戻り値：成功時は { byDay: {日: 空き枠合計}, earliest: {m, d, display} | null }、失敗時は { error: 理由 }。
     earliest は今日以降で最も早い空き（過去日の空きは対象にしない） */
  async function fetchVenueMonth(ctx, code, mk, tinfo) {
    var url = ctx.base + "?date=" + mk.ym + "&coursecode=" + encodeURIComponent(ctx.coursecode) + "&placecode=" + code + "&user=pub";
    var res;
    try {
      res = await fetch(url, { headers: { "Accept": "application/json" }, credentials: "omit" });
    } catch (e) { return { error: "通信エラー" }; }
    if (!res.ok) return { error: "サーバーエラー（" + res.status + "）" };
    var data;
    try { data = await res.json(); } catch (e) { return { error: "応答がJSONではありませんでした" }; }
    if (!data || typeof data !== "object") return { error: "データの形式が想定と違いました" };
    if (data.code && data.code !== "A0001") return { error: "APIがエラーを返しました（コード: " + data.code + "）" };
    if (!Array.isArray(data.body)) return { error: "データの形式が想定と違いました" };
    if (data.body.length === 0) return { error: "データが空でした" };
    var byDay = {};
    var open = [];
    data.body.forEach(function (s) {
      if (!s || typeof s.date !== "string" || s.date.length !== 8) return;
      if (s.date.slice(0, 6) !== mk.ym) return;
      var day = parseInt(s.date.slice(6, 8), 10);
      if (!(day >= 1 && day <= mk.lastDay)) return;
      var cap = parseInt(s.capacity, 10);
      var rsv = parseInt(s.reservation, 10);
      if (isNaN(cap) || isNaN(rsv)) return;
      var rem = cap - rsv;
      if (rem < 0) rem = 0;
      byDay[day] = (byDay[day] || 0) + rem;
      if (rem > 0 && s.date >= tinfo.ymd) open.push({ day: day, start: String(s.starttime || ""), display: String(s.displaytime || "") });
    });
    open.sort(function (a, b) {
      if (a.day !== b.day) return a.day - b.day;
      return a.start < b.start ? -1 : (a.start > b.start ? 1 : 0);
    });
    var earliest = open.length ? { m: mk.m, d: open[0].day, display: open[0].display } : null;
    return { byDay: byDay, earliest: earliest };
  }
  function renderTable(root, results) {
    root.appendChild(el("p", "「残りN人」は、その日に空いている予約枠の合計（時間枠ごとの定員から予約済みを引いた数の合計）です。×は空きなし、－は過ぎた日、空欄はその月に存在しない日です。最新の状況と予約は公式サイトでご確認ください。"));
    root.appendChild(el("p", "セルの色は、緑＝残り50人以上、黄＝残り10〜49人、赤＝残りわずか1〜9人、グレー＝空きなしを表します。"));
    var maxDay = 31;
    var table = el("table");
    table.setAttribute("border", "1");
    table.setAttribute("cellspacing", "0");
    table.setAttribute("cellpadding", "3");
    table.setAttribute("width", "100%");
    var thead = el("thead");
    var trh = el("tr");
    var thV = el("th", "会場");
    thV.setAttribute("bgcolor", "#eef3f8");
    thV.setAttribute("align", "left");
    trh.appendChild(thV);
    var thM = el("th", "月");
    thM.setAttribute("bgcolor", "#eef3f8");
    trh.appendChild(thM);
    for (var d = 1; d <= maxDay; d++) {
      var th = el("th", String(d));
      th.setAttribute("bgcolor", "#eef3f8");
      th.setAttribute("align", "center");
      trh.appendChild(th);
    }
    thead.appendChild(trh);
    table.appendChild(thead);
    var tbody = el("tbody");
    results.forEach(function (r) {
      r.months.forEach(function (mo, mi) {
        var tr = el("tr");
        var tdV = el("td");
        tdV.appendChild(el("strong", r.venue));
        if (mi === 0) {
          if (r.earliest) {
            tdV.appendChild(el("br"));
            tdV.appendChild(el("small", "最速の空き：" + r.earliest.m + "月" + r.earliest.d + "日" + (r.earliest.display ? "（" + r.earliest.display + "）" : "")));
          } else if (r.anyOk) {
            tdV.appendChild(el("br"));
            tdV.appendChild(el("small", "最速の空き：なし（今日以降）"));
          }
        }
        tr.appendChild(tdV);
        tr.appendChild(el("td", mo.label));
        if (mo.error) {
          var tdE = el("td");
          tdE.setAttribute("colspan", String(maxDay));
          tdE.appendChild(redBold("読み取れませんでした（" + mo.error + "）"));
          tr.appendChild(tdE);
        } else {
          for (var d2 = 1; d2 <= maxDay; d2++) {
            var c;
            if (d2 > mo.lastDay) {
              c = el("td", "");
            } else if (mo.pastUntil && d2 <= mo.pastUntil) {
              c = el("td", "－");
              c.setAttribute("bgcolor", "#f4f4f4");
            } else {
              var v = mo.byDay[d2];
              if (v == null || v <= 0) {
                c = el("td", "×");
                c.setAttribute("bgcolor", "#e8e8e8");
              } else {
                c = el("td", "残り" + v + "人");
                c.setAttribute("bgcolor", v >= 50 ? "#c8e6c9" : (v >= 10 ? "#fff0b3" : "#f6c9c9"));
              }
            }
            c.setAttribute("align", "center");
            tr.appendChild(c);
          }
        }
        tbody.appendChild(tr);
      });
    });
    table.appendChild(tbody);
    var fwrap = el("font");
    fwrap.setAttribute("size", "2");
    fwrap.appendChild(table);
    root.appendChild(fwrap);
  }
  function sleep(ms) { return new Promise(function (r) { setTimeout(r, ms); }); }
  async function main() {
    var ctx = findApiContext();
    if (!ctx) {
      showOverlay(function (r) {
        var p1 = el("p");
        p1.appendChild(redBold("カレンダーのデータの読み込み先が分かりませんでした。"));
        r.appendChild(p1);
        r.appendChild(el("p", "このツールは、公式サイトが空き状況カレンダーを表示するときに読み込むデータを使って集約します。先に通常の手順でカレンダー画面を1回開いてから（会場を選んで「進む」を押すところまで進めてください）、もう一度実行してください。"));
      });
      return;
    }
    var statusEl = null;
    showOverlay(function (r) {
      statusEl = el("p", "読み取り中です…（0/" + VENUES.length + "会場）");
      r.appendChild(statusEl);
    });
    var months = monthKeys();
    var tinfo = todayInfo();
    var results = [];
    var fetched = 0;
    for (var vi = 0; vi < VENUES.length; vi++) {
      var venue = VENUES[vi][0];
      var code = VENUES[vi][1];
      var vres = { venue: venue, months: [], earliest: null, anyOk: false };
      for (var mi = 0; mi < months.length; mi++) {
        var mk = months[mi];
        if (fetched > 0) await sleep(300);
        fetched++;
        var got = await fetchVenueMonth(ctx, code, mk, tinfo);
        if (got.error) {
          vres.months.push({ label: mk.label, lastDay: mk.lastDay, error: got.error });
        } else {
          vres.anyOk = true;
          vres.months.push({ label: mk.label, lastDay: mk.lastDay, byDay: got.byDay, pastUntil: mi === 0 ? tinfo.day - 1 : 0 });
          if (!vres.earliest && got.earliest) vres.earliest = got.earliest;
        }
      }
      results.push(vres);
      if (statusEl) statusEl.textContent = "読み取り中です…（" + (vi + 1) + "/" + VENUES.length + "会場）";
    }
    var fresh = showOverlay(function () {});
    renderTable(fresh, results);
  }
  main().catch(function () {
    showOverlay(function (r) { failMessage(r); });
  });
})();

会場の地図と現在地からの距離

全17会場の場所を地図に表示しています。ピンをタップ（クリック）すると、会場名と住所が出ます。「現在地から測る」ボタンを押すと、ブラウザの位置情報を使って各会場までの直線距離を計算し、近い順の一覧を表示します。直線距離なので、実際の道のりや所要時間とは異なります。位置情報はこのページの中だけで使い、外部のサーバーへ送信することはありません。

    住所は警視庁「更新手続の場所」（2026年11月に確認）の掲載情報です。位置情報が取得できない場合は、地図と住所の一覧だけを表示します。地図データ：© OpenStreetMap contributors

    仕組みと限界

    公式サイトは、空き状況カレンダーを表示するときに、専用のデータ配信（カレンダーAPI）から空きデータを受け取っています。このブックマークレットは、あなたがカレンダーを1回表示したときに使われた通信先と講習区分を、ブラウザの記録から再利用し、全17会場について当月と翌月のデータを同じAPIから読み取り、表にまとめます。空き数は、時間枠ごとの「定員 − 予約済み数」を日ごとに合計したものです。あわせて、会場ごとに最も早い空き日も表示します。読み取れなかった会場・月には「読み取れませんでした」と理由（サーバーエラー、データが空だった等）もあわせて表示します（推測で数字を作ることはしません）。このツールはデータを読むだけで、予約の確定はしません。サイト側の仕様が変わると読み取れなくなる場合があります。

    空き状況は、講習区分などの条件によって異なります。このツールは、あなたが公式サイトでカレンダーを表示したときの講習区分のまま読み取ります。
