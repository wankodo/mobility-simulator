公式の予約サイトで会場ごとに分かれている空き状況カレンダーを、1つの表にまとめて見るためのブックマークレット試作品です。

⚠ テスト中 ⚠

このページは試作（テスト版）です。正式版ではありません。ブックマークレットは実際の予約サイトで動作を確認し、判明した画面構造（カレンダーは入力画面とは別の専用ページにあり、日付はラジオボタンで並ぶ形式）に合わせて改修しましたが、全会場の集約が実地で正しく動くかの最終確認はこれからです。画面の構造によっては正しく読み取れない場合があります。空き状況の最終確認と予約は、必ず公式サイトで行ってください。

使い方（3ステップ）

1
公式予約サイトでログインする
警視庁運転免許手続予約サイトを開き、いつも通りご自身で手続を進めて、「更新場所を選択してください。」の画面か、空き状況カレンダーのページを表示します。
2
用意したブックマークを実行する
このページのコードを登録したブックマークを、会場選択の画面かカレンダーのページを開いた状態で実行します。ブックマークの登録は最初の1回だけです（登録方法は下の「ブックマークの登録方法」へ）。
3
会場ごとの空き一覧が表示される
各会場のカレンダーを読み取り、ページの先頭にまとめた表が表示されます。○は予約できる日、×は空きなし、数字が出る場合は空いている予約枠の数です。読み取れなかった会場には、理由もあわせて表示されます。

実行する画面について：会場選択画面（「更新場所を選択してください。」）で実行すると全会場を集約します。カレンダー画面で実行した場合は、表示中の会場だけが対象です。

このツールについて

警視庁の運転免許手続予約サイトでは、空き状況カレンダーは会場を1つずつ選んで見る仕組みになっています。このツールは、ログイン済みの公式サイトのページでブックマークレットを実行すると、会場ごとのカレンダーを順番に読み取り、1つの表にまとめて表示する試作品です。会場選択画面で実行すると全会場分を、カレンダー画面で実行すると表示中の会場分をまとめます。

個人情報の扱い：予約用IDなどの情報は、お使いのブラウザの中だけで扱われます。このブックマークレットは、公式サイトと同じドメイン内のページを読むだけで、外部のサーバーへ情報を送信する処理は一切入っていません。ソースコードを下に全文公開していますので、実行前に中身を確認できます。

  function parseEmbeddedCalendar(doc) {

    function add(y, mo, d, ok) {
      if (!(mo >= 1 && mo <= 12 && d >= 1 && d <= 31)) return;
      var label = y + "年" + mo + "月";
      if (!found[label]) { found[label] = {}; keys.push(label); }
      if (!(d in found[label])) { found[label][d] = ok ? "○" : "×"; total++; }
    }
    var m;
    var re1 = /(\d{4})[\/-](\d{1,2})[\/-](\d{1,2})["']?\s*[:=]\s*["']?(true|false|1|0|○|×|◯|不可|可)/g;
    while ((m = re1.exec(text))) add(parseInt(m[1], 10), parseInt(m[2], 10), parseInt(m[3], 10), okVal(m[4]));
    var re2 = /["'](?:date|day|ymd)["']?\s*:\s*["'](\d{4})[\/-](\d{1,2})[\/-](\d{1,2})["'][\s\S]{0,80}?["'](?:available|avail|aki|status|flag|ok)["']?\s*:\s*["']?(true|false|1|0|○|×)/g;
    while ((m = re2.exec(text))) add(parseInt(m[1], 10), parseInt(m[2], 10), parseInt(m[3], 10), okVal(m[4]));
    if (total < 15) return null;
    return { rows: keys.map(function (k) { return { month: k, map: found[k] }; }), method: "embedded", container: null };
  }

  function formRequest(form, control, baseUrl) {
    var method = (form.getAttribute("method") || "get").toLowerCase();

    try { url = new URL(form.getAttribute("action") || baseUrl, baseUrl); } catch (e) { return null; }

    fields.forEach(function (f) {

      var type = (f.getAttribute("type") || "").toLowerCase();
      if (f === control) { data.append(f.name, f.value != null ? f.value : ""); return; }
      if (type === "submit" || type === "button" || type === "image" || type === "reset" || type === "file") return;
      if ((type === "checkbox" || type === "radio") && !f.checked) return;
      if (f.tagName === "SELECT") {
        var o = f.options[f.selectedIndex];
        data.append(f.name, o ? o.value : "");
      } else {
        data.append(f.name, f.value != null ? f.value : "");
      }
    });
    if (control && control.name && !data.has(control.name)) {
      data.append(control.name, control.value != null ? control.value : "");
    }
    if (method === "post") return { method: "POST", url: url.href, body: data.toString() };
    url.search = data.toString();

  function deriveCalendarUrl(urlStr) {
    try {
      var url = new URL(urlStr);
      if (url.pathname.indexOf("/calendar/") >= 0) return url.href;
      var seg = url.pathname.split("/");
      if (seg.length >= 5) {
        seg.splice(seg.length - 3, 0, "calendar");

        return url.href;
      }
    } catch (e) { /* 導けない場合は null */ }

  }

      }
    });

  }

  /* 未選択状態の切り分け用：カレンダーとして成立するか（15日分そろうか）は問わず、
     日付らしい最小要素が何日分あるかだけを数える（collectDayCells は15日未満だと空を返すため流用できない） */
  function countDayishDays(doc) {
    var body = doc.body;
    if (!body) return 0;
    var seen = {};
    var all = body.querySelectorAll("*");
    all.forEach(function (e) {
      var tag = e.tagName;
      if (tag === "SCRIPT" || tag === "STYLE" || tag === "NOSCRIPT" || tag === "SELECT" || tag === "TEXTAREA" || tag === "OPTION") return;
      if (tag === "INPUT" && (e.getAttribute("type") || "").toLowerCase() === "hidden") return;
      if (e.closest && e.closest("select, textarea")) return;
      var info = dayInfo(e);
      if (!info || info.day < 1 || info.day > 31) return;
      if (/^(人|枠|名|円|時|分|秒)/.test(info.rest)) return;
      var desc = e.querySelectorAll("*");
      for (var i = 0; i < desc.length; i++) {
        var di = dayInfo(desc[i]);
        if (di && di.day === info.day) return;
      }
      seen[info.day] = 1;
    });
    return Object.keys(seen).length;
  }

  async function fetchVenue(req) {
    var res;
    try { res = await doFetch(req); } catch (e) { return { error: "通信エラー" }; }
    if (!res.ok) return { error: "サーバーエラー（" + res.status + "）" };
    var finalUrl = res.url || req.url;
    var html;
    try { html = await res.text(); } catch (e) { return { error: "通信エラー" }; }
    var doc = new DOMParser().parseFromString(html, "text/html");
    var cal = parseCalendar(doc);
    var onCalendarPath = finalUrl.indexOf("/calendar/") >= 0;
    var cdVal = choiceDetailValue(doc);
    if (!cal) {
      if (!onCalendarPath) return { error: "応答が入力ページでした" };
      /* 会場未選択のまま返ってきた応答（日要素が少しだけ＝直近候補日の帯のような別ウィジェット）を切り分ける */
      if (cdVal === "") {
        var ish = 0;
        try { ish = countDayishDays(doc); } catch (e) { ish = 0; }
        if (ish > 0 && ish < 15) {
          return { error: "会場が未選択の状態でした：カレンダーが" + ish + "日分だけでした" };
        }
      }
      return { error: "カレンダーは取れたが日要素が見つかりませんでした" };
    }
    if (cdVal === "" && countCalDays(cal) < 15) {
      return { error: "会場が未選択の状態でした：カレンダーが" + countCalDays(cal) + "日分だけでした" };
    }
    var rows = cal.rows.slice();
    if (rows.length < 2) {
      var nm = nextTarget(doc, finalUrl);
      if (nm && nm.url !== finalUrl) {
        try {
          var r2 = await doFetch(nm);
          if (r2.ok) {
            var d2 = new DOMParser().parseFromString(await r2.text(), "text/html");
            var c2 = parseCalendar(d2);
            if (c2) {
              c2.rows.forEach(function (row) {
                var dup = false;
                rows.forEach(function (x) { if (x.month === row.month) dup = true; });
                if (!dup) rows.push(row);
              });
            }
          }
        } catch (e) { /* 翌月が読めなくても当月分は表示する */ }
      }
    }
    return { rows: rows, method: cal.method, uncertain: !!cal.uncertain };
  }

ブックマークレットは、会場選択画面のフォームに入力済みの条件（講習区分や免許証の種類など）をそのまま保持し、会場の選択だけを1会場ずつ切り替えて、カレンダー専用のページへ読みに行きます（カレンダーは入力画面とは別のページにあることが、実地の確認で分かりました）。読み取りは同じドメイン内だけです。カレンダーの形式は会場ごとに判定し、どの方式で読んだか（ラジオボタン式・カレンダー表・埋め込みデータ・汎用）を表の中に表示します。空きは「選べる日＝○、選べない日＝×」で読み取り、枠の数が表示されている場合はその数字を使います。選べる日と選べない日の見分け材料が画面から見つからない会場には「要確認」と付けます。読み取れなかった会場には「読み取れませんでした」と理由（応答が入力ページだった、会場が未選択のまま返ってきた、サーバーエラーなど）もあわせて表示します（推測で数字を作ることはしません）。翌月分は、サイト側の月送りがプログラムで動く仕組みのため取得できない場合があります（その場合は当月分のみを表示し、その旨を注記します）。うまく集約できなかった場合は、下の「構造チェック」を実行して、結果を送ってください。

空き状況は、選択した免許証の種類（「免許証のみ」か「マイナ免許証」か）によって異なります。このツールは、あなたが公式サイトで選択した条件のまま読み取ります。
