免許更新の予約空きまとめ【テスト中】

公式の予約サイトで会場ごとに分かれている空き状況カレンダーを、1つの表にまとめて見るためのブックマークレット試作品です。

⚠ テスト中 ⚠

このページは試作（テスト版）です。正式版ではありません。ブックマークレットは実際の予約サイトのログイン後画面では動作未検証で、画面の構造によっては正しく読み取れない場合があります。空き状況の最終確認と予約は、必ず公式サイトで行ってください。

使い方（3ステップ）

1
公式予約サイトでログインする
警視庁運転免許手続予約サイトを開き、いつも通りご自身で手続を進めて、空き状況カレンダーのページを表示します。
2
用意したブックマークを実行する
このページのコードを登録したブックマークを、カレンダーのページを開いた状態で実行します。ブックマークの登録は最初の1回だけです（登録方法は下の「ブックマークの登録方法」へ）。
3
会場ごとの空き一覧が重なって表示される
各会場のカレンダーを読み取り、画面の上にまとめた表が重なって表示されます。数字は空いている予約枠の数です。

このツールについて

警視庁の運転免許手続予約サイトでは、空き状況カレンダーは会場を1つずつ選んで見る仕組みになっています。このツールは、ログイン済みの公式サイトのページでブックマークレットを実行すると、会場ごとのカレンダーを順番に読み取り、1つの表にまとめて表示する試作品です。

個人情報の扱い：予約用IDなどの情報は、お使いのブラウザの中だけで扱われます。このブックマークレットは、公式サイトと同じドメイン内のページを読むだけで、外部のサーバーへ情報を送信する処理は一切入っていません。ソースコードを下に全文公開していますので、実行前に中身を確認できます。

ブックマークの登録方法

最初に1回だけ、このページのコードをブラウザのブックマークに登録します。スマートフォン向けの手順を先に載せています。

まず、コードをコピーしてください
下のボタンを押すと、ブックマークに登録するためのコード（ブックマークレット）がコピーされます。

コピーしました

ボタンでコピーできない場合は、上の欄の文字列を長押し（タップ）で全選択してコピーしてください。コードは「javascript:」で始まる長い文字列です。1文字も変えず、そのまま使います。

iPhone（Safari）の場合

  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Safariでこのページをブックマークに追加します。共有ボタン（四角から矢印が出たマーク）を押し、「ブックマークを追加」を選んで保存します。名前は「空きまとめ」など、短くて分かりやすいものにしておくと後の手順が楽です。
  3. Safariのブックマークを開き、「編集」を押して、今作ったブックマークを選びます。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインしてカレンダーを表示した状態で、ブックマークを開いて「空きまとめ」をタップすると実行されます。
  6. もう一つの実行方法：公式サイトを開いた状態で、アドレスバーにブックマーク名（例：空きまとめ）と入力すると候補に表示されるので、それをタップしても実行できます。

Android（Chrome）の場合

  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Chromeでこのページをブックマークします（アドレスバーの☆、またはメニューの「スター」）。
  3. メニューの「ブックマーク」から今のブックマークを開き、「編集」を押します。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインしてカレンダーを表示した状態で、アドレスバーにブックマーク名を入力し、候補に出てきたものをタップすると実行されます（ブックマークの一覧からタップしただけでは実行されないことがあるため、この方法が確実です）。

下のボタンをブックマークバーへドラッグして登録します。登録後は、公式サイトのカレンダーページでそのブックマークをクリックすると実行されます。

  function venueOf(text) {
    if (!text) return null;
    var t = String(text).replace(/[\s　]+/g, "");
    for (var i = 0; i < VENUES.length; i++) {
      if (t.indexOf(VENUES[i].replace(/[\s　]+/g, "")) >= 0) return VENUES[i];
    }
    return null;
  }
  function monthLabel(doc) {
    var t = doc && doc.body ? doc.body.textContent || "" : "";
    var m = t.match(/(\d{4})年\s*(\d{1,2})月/);
    if (m) return m[1] + "年" + m[2] + "月";
    var m2 = t.match(/(\d{1,2})月の空き|(\d{1,2})月分/);
    if (m2) return (m2[1] || m2[2]) + "月";
    return "";
  }
  function cellText(c) {
    var parts = [];
    (function walk(node) {
      var kids = node.childNodes;
      for (var i = 0; i < kids.length; i++) {
        var n = kids[i];
        if (n.nodeType === 3) {
          var t = n.textContent.replace(/[\s　]+/g, " ").trim();
          if (t) parts.push(t);
        } else if (n.nodeType === 1) {
          if (n.tagName === "BR") parts.push(" ");
          else walk(n);
        }
      }
    })(c);
    return parts.join(" ");
  }
  function parseCalendar(doc) {
    var tables = doc.querySelectorAll("table");
    var best = null;
    for (var ti = 0; ti < tables.length; ti++) {
      var cells = tables[ti].querySelectorAll("td");
      var map = {};
      var days = 0;
      var slots = 0;
      cells.forEach(function (c) {
        var raw = cellText(c);
        var dm = raw.match(/^(\d{1,2})(?!\d)/);
        if (!dm) return;
        var day = parseInt(dm[1], 10);
        if (day < 1 || day > 31) return;
        if (day in map) return;
        var rest = raw.slice(dm[0].length).trim();
        var status = "";
        var nm = rest.match(/(\d+)\s*人/) || rest.match(/残り\s*(\d+)\s*枠/) || rest.match(/^(\d+)$/);
        if (nm) { status = nm[1]; slots++; }
        else if (rest.indexOf("○") >= 0 || rest.indexOf("◯") >= 0) status = "○";
        else if (rest.indexOf("△") >= 0) status = "△";
        else if (rest.indexOf("×") >= 0 || rest.indexOf("✕") >= 0) status = "×";
        else if (rest) status = rest.slice(0, 8);
        map[day] = status;
        days++;
      });
      if (days >= 15 && (!best || slots > best.slots)) best = { map: map, slots: slots };
    }
    return best;
  }
  function currentVenue(doc) {
    var sels = doc.querySelectorAll("select");
    for (var i = 0; i < sels.length; i++) {
      var opt = sels[i].options[sels[i].selectedIndex];
      var v = opt ? venueOf(opt.textContent) : null;
      if (v) return v;
    }
    var heads = doc.querySelectorAll("h1, h2, h3");
    for (var j = 0; j < heads.length; j++) {
      var hv = venueOf(heads[j].textContent);
      if (hv) return hv;
    }
    return venueOf(doc.title);
  }
  function venueLinks(doc) {
    var out = [];
    var seen = {};
    var anchors = doc.querySelectorAll("a[href]");
    anchors.forEach(function (a) {
      var v = venueOf(a.textContent || "");
      if (!v || seen[v]) return;
      var href = a.getAttribute("href");
      if (!href || href.charAt(0) === "#") return;
      var u;
      try { u = new URL(href, location.href); } catch (e) { return; }
      if (u.origin !== location.origin) return;
      seen[v] = 1;
      if (u.href === location.href) return;
      out.push({ venue: v, url: u.href });
    });
    return out;
  }
  function el(tag, text, style) {
    var e = document.createElement(tag);
    if (text != null) e.textContent = text;
    if (style) e.setAttribute("style", style);
    return e;
  }

  function renderTable(root, results, linkCount) {
    root.appendChild(el("p", "数字は空いている予約枠の数です。空欄は読み取れなかった日、×は空きなしとして読み取った日です。最新の状況と予約は公式サイトでご確認ください。", "margin:4px 0 10px;"));

    if (cur) results.push({ venue: currentVenue(document) || "表示中の会場", month: monthLabel(document), map: cur.map });
    var links = venueLinks(document);
    for (var i = 0; i < links.length && i < 20; i++) {
      try {
        var res = await fetch(links[i].url, { credentials: "same-origin" });
        if (res.ok) {
          var html = await res.text();
          var doc = new DOMParser().parseFromString(html, "text/html");
          var cal = parseCalendar(doc);
          if (cal) results.push({ venue: links[i].venue, month: monthLabel(doc), map: cal.map });
        }
      } catch (e) { /* skip this venue */ }
      await sleep(300);
    }
    var fresh = showOverlay(function () {});
    if (results.length === 0) { failMessage(fresh); return; }
    renderTable(fresh, results, links.length);
  }
  main().catch(function () {
    showOverlay(function (r) { failMessage(r); });
  });
