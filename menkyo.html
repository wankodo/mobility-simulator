免許更新の予約空きまとめ【テスト中】

公式の予約サイトで会場ごとに分かれている空き状況カレンダーを、1つの表にまとめて見るためのブックマークレット試作品です。

← トップへ戻る

⚠ テスト中 ⚠

このページは試作（テスト版）です。正式版ではありません。ブックマークレットは実際の予約サイトで一度動作を確認しましたが、全会場の集約はまだ改修中の段階で、画面の構造によっては正しく読み取れない場合があります。空き状況の最終確認と予約は、必ず公式サイトで行ってください。

使い方（3ステップ）

1
公式予約サイトでログインする
警視庁運転免許手続予約サイトを開き、いつも通りご自身で手続を進めて、「更新場所を選択してください。」の画面か、空き状況カレンダーのページを表示します。
2
用意したブックマークを実行する
このページのコードを登録したブックマークを、会場選択の画面かカレンダーのページを開いた状態で実行します。ブックマークの登録は最初の1回だけです（登録方法は下の「ブックマークの登録方法」へ）。
3
会場ごとの空き一覧が重なって表示される
各会場のカレンダーを読み取り、画面の上にまとめた表が重なって表示されます。○は予約できる日、×は空きなし、数字が出る場合は空いている予約枠の数です。

実行する画面について：会場選択画面（「更新場所を選択してください。」）で実行すると全会場を集約します。カレンダー画面で実行した場合は、表示中の会場だけが対象です。

このツールについて

警視庁の運転免許手続予約サイトでは、空き状況カレンダーは会場を1つずつ選んで見る仕組みになっています。このツールは、ログイン済みの公式サイトのページでブックマークレットを実行すると、会場ごとのカレンダーを順番に読み取り、1つの表にまとめて表示する試作品です。会場選択画面で実行すると全会場分を、カレンダー画面で実行すると表示中の会場分をまとめます。

個人情報の扱い：予約用IDなどの情報は、お使いのブラウザの中だけで扱われます。このブックマークレットは、公式サイトと同じドメイン内のページを読むだけで、外部のサーバーへ情報を送信する処理は一切入っていません。ソースコードを下に全文公開していますので、実行前に中身を確認できます。

ブックマークの登録方法

最初に1回だけ、このページのコードをブラウザのブックマークに登録します。スマートフォン向けの手順を先に載せています。

まず、コードをコピーしてください
下のボタンを押すと、ブックマークに登録するためのコード（ブックマークレット）がコピーされます。

コピーしました

ボタンでコピーできない場合は、上の欄の文字列を長押し（タップ）で全選択してコピーしてください。コードは「javascript:」で始まる長い文字列です。1文字も変えず、そのまま使います。

iPhone（Safari）の場合

  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Safariでこのページをブックマークに追加します。共有ボタン（四角から矢印が出たマーク）を押し、「ブックマークを追加」を選んで保存します。名前は「空きまとめ」など、短くて分かりやすいものにしておくと後の手順が楽です。
  3. Safariのブックマークを開き、「編集」を押して、今作ったブックマークを選びます。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインして会場選択画面かカレンダーを表示した状態で、ブックマークを開いて「空きまとめ」をタップすると実行されます。
  6. もう一つの実行方法：公式サイトを開いた状態で、アドレスバーにブックマーク名（例：空きまとめ）と入力すると候補に表示されるので、それをタップしても実行できます。

Android（Chrome）の場合

  1. 上の「コードをコピー」ボタンで、コードをコピーします。
  2. Chromeでこのページをブックマークします（アドレスバーの☆、またはメニューの「スター」）。
  3. メニューの「ブックマーク」から今のブックマークを開き、「編集」を押します。
  4. URL欄の内容を全部消して、コピーしたコードを貼り付けて保存します。
  5. 使い方：公式予約サイトでログインして会場選択画面かカレンダーを表示した状態で、アドレスバーにブックマーク名を入力し、候補に出てきたものをタップすると実行されます（ブックマークの一覧からタップしただけでは実行されないことがあるため、この方法が確実です）。

  function cellText(c) {
    var parts = [];
    (function walk(node) {
      var kids = node.childNodes;
      for (var i = 0; i < kids.length; i++) {
        var n = kids[i];
        if (n.nodeType === 3) {
          var t = n.textContent.replace(/[\s　]+/g, " ").trim();

  function formRequest(form, control, baseUrl) {
    var method = (form.getAttribute("method") || "get").toLowerCase();
    var url;
    try { url = new URL(form.getAttribute("action") || baseUrl, baseUrl); } catch (e) { return null; }
    if (url.origin !== location.origin) return null;

  async function fetchRows(req, maxMonths) {

    showOverlay(function (r) { r.appendChild(el("p", "読み取り中です…（会場ごとに順番に読みます）")); });
    var results = [];
    var have = {};
    var cur = parseCalendar(document);
    if (cur) {
      var cv = currentVenue(document) || "表示中の会場";
      var rows = [{ month: monthLabel(document), map: cur.map }];
      var nm = nextTarget(document, location.href);
      if (nm) {
        try {
          var extra = await fetchRows(nm, 1);
          if (extra) rows = rows.concat(extra);
        } catch (e) { /* 翌月が読めなくても当月分は表示する */ }
      }
      results.push({ venue: cv, rows: rows });
      have[cv] = 1;
    }
    var cands = venueCandidates(document, location.href);
    var fetched = 0;
    for (var i = 0; i < cands.length && i < 25; i++) {
      var c = cands[i];
      if (have[c.venue]) continue;
      have[c.venue] = 1;
      if (!c.req) { results.push({ venue: c.venue, error: true }); continue; }
      if (fetched > 0) await sleep(300);
      fetched++;
      try {
        var rws = await fetchRows(c.req, 2);
        if (rws) results.push({ venue: c.venue, rows: rws });
        else results.push({ venue: c.venue, error: true });
      } catch (e) {
        results.push({ venue: c.venue, error: true });
      }
      await sleep(300);
    }
    var fresh = showOverlay(function () {});
    if (results.length === 0) { failMessage(fresh); return; }
    renderTable(fresh, results, cands.length);
  }
  main().catch(function () {
    showOverlay(function (r) { failMessage(r); });
  });

ブックマークレットは、会場選択画面にある会場のボタン（リンク式・フォームのボタン式のどちらにも対応を試みます。辿るのは同じドメイン内だけです）を順番にたどって各会場のカレンダーを読み、表にまとめます。カレンダーは翌月分まで読み取ります。空きは「選べる日＝○、選べない日＝×」で読み取り、枠の数が表示されている場合はその数字を使います。たどれない会場や、カレンダーの形式が想定と違う場合は、その会場に「読み取れませんでした」と表示します（推測で数字を作ることはしません）。うまく集約できなかった場合は、下の「構造チェック」を実行して、結果を送ってください。
